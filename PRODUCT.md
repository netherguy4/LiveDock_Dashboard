# Product

## Register

product

## Users

Solo developers and self-hosters managing their own VPS or homelab. The builder is the user — they are technical, context-aware, and want signal fast. They open this dashboard at a glance, not to explore.

## Product Purpose

LiveDock is a self-hosted server monitoring dashboard. It surfaces container status, system metrics (CPU, memory, disk, network), request throughput, and health at a glance — all from a single screen. Success means the user can diagnose a problem in seconds without context-switching.

## Brand Personality

Precise, calm, trustworthy. Like Vercel's dashboard — spacious enough to breathe, dense enough to be useful. Never decorative. Every element either carries signal or stays out of the way.

## Anti-references

- Grafana: not overwhelming — avoid infinite panels, nested menus, configuration overload.
- Generic Bootstrap admin: not off-the-shelf CRUD. No banded table rows, no card-grid sameness, no "template" feeling.

## Design Principles

1. **Signal over chrome.** Every visible element should reduce time-to-diagnosis, not add visual weight.
2. **Calm confidence.** The interface should feel like the system is under control — not alerting constantly, not shouting status.
3. **Density with breath.** Show a lot without overwhelming — tight information hierarchy, generous spacing at the section level.
4. **Predictable layout.** The user glances at this repeatedly; elements should never move or surprise.
5. **Theme integrity.** Dark and light modes are equal citizens — neither is an afterthought.

## Accessibility & Inclusion

Not a current priority. Practical baseline only (keyboard nav for interactive controls, sufficient contrast for primary text).
